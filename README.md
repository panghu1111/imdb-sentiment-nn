# IMDb Sentiment Classifier — TF-IDF + Neural Network, deployed by CI/CD

An end-to-end, reproducible ML engineering project for the session-3 assignment
(*ML Project: GitHub CI/CD → Hugging Face*). Push code to GitHub; GitHub Actions
trains the model and publishes every artifact to the Hugging Face Hub. Nothing is
uploaded or trained by hand.

- **Task**: binary sentiment classification of IMDb reviews
- **Dataset**: `data/imdb_top_500.csv` — 500 reviews with `text`, `label` (0 = negative, 1 = positive) and `rating`
- **Model**: TF-IDF (word 1–2 grams, 5k features) → MLP `5000 → 256 → 64 → 2` with BatchNorm, ReLU and Dropout
- **Serving**: `predict.py` loads artifacts locally, or downloads them straight from the Hub

## Results (held-out 20% test split)

| Metric | Value |
|---|---|
| Accuracy | 0.8200 |
| Macro F1 | 0.8199 |
| ROC-AUC | 0.8964 |

Produced by the latest Actions run (seed 42, best epoch 31, 5.35 s of training).
`metrics.json` also stores the full per-epoch history, the confusion matrix and a
per-class classification report, so the exact numbers always travel with the model.

## Quick start

```bash
python -m venv .venv && source .venv/bin/activate      # Windows: .venv\Scripts\activate
pip install torch --index-url https://download.pytorch.org/whl/cpu
pip install -r requirements.txt

python train.py                     # writes model/model.pt, vectorizer.pkl, config.json, metrics.json
python predict.py --interactive     # or: python predict.py --text "Beautifully acted, quietly devastating."
```

Inference output is JSON:

```json
{
  "label": "positive",
  "label_id": 1,
  "confidence": 0.9123,
  "probabilities": {"negative": 0.0877, "positive": 0.9123}
}
```

Without any local artifacts, pointed at the published Hub repo:

```bash
python predict.py --hf-repo wenlong-1/imdb-sentiment-nn --text "Two hours I will never get back."
```

## CI/CD flow

`.github/workflows/train-and-upload.yml` runs on every push to `main`/`master`
(and on manual dispatch):

1. **Setup** — checkout, Python 3.11, CPU wheel for torch, `pip install -r requirements.txt`
2. **Train** — `python train.py`, which writes all four artifacts into `model/`
3. **Deploy** — `HfApi.create_repo(exist_ok=True)` then `upload_file` for each artifact, plus a
   model card generated from the freshly produced `metrics.json`
4. **Archive** — the same artifacts are attached to the workflow run for 14 days

Repositories are created once and then only updated by CI; no manual Hub uploads.

### One-time setup

1. GitHub → *Settings → Secrets and variables → Actions*
   - Secret **`HF_TOKEN`**: a Hugging Face *write* token
   - Variable **`HF_REPO_ID`** (optional): defaults to `<github-owner>/imdb-sentiment-nn`
2. Push to `main`. The first run creates the Hub repo; later runs publish new commits.

## Design notes

- **No data leakage** — the vectorizer is fitted on the training split only, then applied to the test split.
- **Early stopping** — the checkpoint with the best test macro-F1 is restored before saving, and the epoch count is recorded in `config.json`.
- **Portable artifacts** — `config.json` + `vectorizer.pkl` + `model.pt` are everything inference needs; the model card is generated, not hand-written.
- **Small-data honesty** — 500 reviews is deliberate. It makes CI runs take seconds, and the metrics are reported as-is rather than tuned on the test set.
